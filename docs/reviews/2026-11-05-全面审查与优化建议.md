## 二、调研得到的优化建议（核实过的事实已标出）

已核实的本机事实：postpane 把 `.cargo/config.toml` 的 `[build] target-dir = "target"` 提交进了仓库，`Cargo.toml` 没有任何 `[profile]` 配置；postpane 有 23 个 worktree（1 个被会话锁着）；`~/.codex/sessions` 有 26 GB；已装应用的签名要求就是当次构建的 cdhash。

| 优先级 | 建议 | 在哪改 | 收益 / 代价 |
|---|---|---|---|
| 高 | postpane 的 `Cargo.toml` 加 `[profile.dev] debug = "line-tables-only"`、`[profile.dev.package."*"] debug = false`；worktree 里不跑 release 构建；PR 合并后用 `git worktree remove` 删掉整个 worktree | **postpane 项目**（不在磁盘瘦身里改） | 调研员估计每个 worktree 从约 7.7 GB 降到 3–4 GB（推断，参照 delta-rs 从 3.1 GB 降到 2.1 GB）；代价是调试时看不到局部变量 |
| 高 | worktree 构建产物不再要求「PR 已合并」：没被锁、cargo 锁拿得到、闲置 ≥ 3 天就默认勾选；每个项目设预算（比如 postpane 不超过 30 GB），超了从最久没用的开始建议清；活跃的 worktree 可以只清 `target/release` | 磁盘瘦身 `WorktreeScanner` | 直接压住「一天掉 20 GB」；被清的下次要重编 |
| 高 | 判断「正在用」改用锁：读 `git worktree list --porcelain` 里 `locked … (pid N)`，删除前对 `target/debug/.cargo-lock` 拿非阻塞 `flock` 并持有到删完；直接删除前要求 `CACHEDIR.TAG` 签名正确 | 磁盘瘦身 | 比匹配命令行可靠，也消除检查和删除之间的时间差（flock 对 cargo 1.99 是否适用要实测） |
| 高 | 用钥匙串「证书助理」建一个自签名代码签名证书（如 `DiskSlim Local`），`bundle.sh` 改用它签名；签名要求变成「标识符 + 证书」，重新打包后完全磁盘访问不再失效 | 用户建证书（一次性），然后改 `bundle.sh` | 来源报告重装 6 次辅助功能权限都还在；完全磁盘访问是同一机制（推断） |
| 高 | 按掉速提醒：每 5 分钟读一次可用空间（很便宜），2 小时内掉超过 8 GB、或照最近速度几小时后会低于 30 GB，就立刻扫描并指出是哪个 worktree | 磁盘瘦身 | 针对一天掉 20 GB 的情况；调研员的设计建议，没有直接来源 |
| 中 | 扫描范围：用 `git worktree list` 列 worktree，不写死路径；列出主仓库的 `target/`（postpane 有 7 GB）、闲置 worktree 的 `node_modules`、Swift `.build`；标出已合并未删的 worktree | 磁盘瘦身 | |
| 中 | 大小计量：按 inode 去掉重复硬链接；APFS 克隆会被高估，界面标「估计值」；读不全的位置标「至少 X」，不悄悄算 0 | 磁盘瘦身 | |
| 中 | 通知授权改到用户打开提醒开关时请求；被拒时给按钮打开系统设置的通知页；可考虑静默投递（provisional） | 磁盘瘦身 | |
| 中 | 唤醒后马上检查（`NSWorkspace.didWakeNotification`），重扫描交给 `NSBackgroundActivityScheduler` | 磁盘瘦身 | |
| 中 | Codex 对话记录 26 GB 按月显示，提示可以在 Codex 里处理或把旧月份挪到外置盘（已经是 zst 压缩，原地再压没用）；Docker / Colima 用 `docker system df` 只读显示能回收多少 | 磁盘瘦身 | |
| 低 | 首页加一行「系统可自动释放 X、本地快照 N 个」（本机 important 口径比现在多 1.4 GB，没有本地快照）；主数字不变 | 磁盘瘦身 | |
| 低 | 下载项进废纸篓前用 `lsof` 查是否正被打开；识别 iCloud 占位文件；遍历不跨卷；另加只追加的审计日志 | 磁盘瘦身 | |

不建议：多个 worktree 共享 `CARGO_TARGET_DIR` / `build-dir` 作为默认（并发编译互相等锁，多个项目报过拿到别的 worktree 的旧 crate）；sccache 省时间不省磁盘。
