A · 容量仪表

像系统自带的面板：先看磁盘还剩多少、被什么占着，再按三个标签分开处理。

点开第一眼
剩余空间、健康状态、一条构成色条。
怎么清
按类别分组的勾选清单，默认只勾「安全」项，一键移到废纸篓。
适合
想一次看全、习惯自己勾选的时候。
代价
信息最全也最密；不太能回答「这几天是谁涨的」。

跟随系统浅色 / 深色。菜单栏图标直接显示剩余 GB。

B · 涨幅雷达

不先问「现在有多满」，先问「这几天是谁吃掉的」。对准你说的「看不见的地方」。

点开第一眼
7 天可用空间曲线和一个大数字：掉了多少。
怎么清
按增量排「肇事者」，每一行直接给处理按钮，下载区只是其中一行。
适合
空间突然没了、想不起来干了什么的时候。今天 postpane 那 78 GB 就是这种。
代价
需要每天记一次快照，装好第一周没有曲线；下载区的批量勾选要再点进去一层。

固定深色。菜单栏图标在快满时显示红色箭头和剩余量。示意的是 11 月 3 日清理前的状态。

C · 待清理收件箱

不给你一张大清单，而是一次只问一件事，像处理收件箱。专治「不会清、不敢清」。

点开第一眼
一张卡：这是什么、为什么建议清、能腾出多少。
怎么清
三个按钮：移到废纸篓 / 保留（以后不再问）/ 下周再问。点完自动下一张。
适合
每周五收到通知，一分钟处理完；判断全由工具先做好。
代价
看不到全貌；要一次清一大批时比 A 慢。

固定浅色。菜单栏图标显示待决定的数量，像未读角标。
