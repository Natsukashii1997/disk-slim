磁盘瘦身：顶栏加一个缩小键

三版只差在缩小键长什么样，位置都在刷新键 ↻ 右边。点一下面板就收起，回到它来的地方（驿窗挂件 / 悬浮球 / 菜单栏图标），和现在按 Esc、点别处收起是同一个动作。每块面板都能真的点：点缩小键收起，点右上角挂件再打开。

甲 · 同款线条和 ↻ 一样的灰色细线，没有底
点「—」收起

最安静，像系统自带的。缺点是小，和 ↻ 挨着不太显眼。

乙 · 深色小块照你发的第二张图：深色圆角块 + 白横线
点深色小块收起

一眼能找到。浅色面板上它是唯一的深色块，比 ↻ 抢眼。

丙 · 浅底圆钮成对↻ 和 — 都加一层淡灰圆底
点「—」圆钮收起

两个键成一对，好点、看得出是按钮。会顺带给 ↻ 也加上圆底。

要你定的三件事

① 选甲、乙、丙哪一版。

② 你发的第二张小图（深色块中间一道横线）是想要的按钮样子，还是想要的缩小后的样子（面板缩成一个小深色块停在边上）？这页按「按钮样子」做；如果是后者，那是新做一种缩小状态，要另出三版。

③ 丙会顺带改 ↻ 的样子，↻ 属于今天定稿的「雾光」首页，选丙就算你同意改它。
