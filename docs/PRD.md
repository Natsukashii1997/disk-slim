# 磁盘瘦身（disk-slim）需求

更新：2026-11-05。来源：常浩与 Claude 的会话「Claude 存储｜空间清理」。

## 1. 为什么做

2026-11-05 数据盘 460 GB 只剩 6.7 GB。手动排查后，不删任何项目源码和对话记录，就腾出了约 84 GB。其中约 78 GB 是 postpane 14 个 PR 已合并的 worktree 留下的 Rust `target/`，用户完全不知道它们存在。

两个痛点：

- **看得见的地方不会批量清**：下载文件夹里不断进新东西，很多只是临时用一下，越堆越多，又不知道哪些能删。
- **看不见的地方不知道、想不起来**：构建产物、包管理器缓存、备份快照、虚拟机等，悄悄占掉几十 GB。

## 2. 调研结论（2026-11-05）

| 工具 | 能做什么 | 缺什么 |
|---|---|---|
| [Mole](https://github.com/tw93/Mole)（免费 CLI） | 清缓存、清项目构建产物、磁盘分析；进废纸篓、支持 `--dry-run`、有操作日志 | 不认识「PR 已合并」；没有涨幅追踪；英文命令行 |
| [Hazel](https://www.noodlesoft.com/?p=868)（付费） | 下载文件夹按「上次打开时间」自动进废纸篓 | 只管看得见的文件夹 |
| macOS「30 天后自动清空废纸篓」 | 系统设置自带 | 只管废纸篓 |
| CleanMyMac / DaisyDisk 等 | 一站式清理 / 可视化 | 订阅制；不懂开发者产物；没有「谁涨的」 |

同类工具公认的安全做法：先预览再清；用户文件进废纸篓而不是直接删；默认只勾低风险项；高风险项永不自动清；每次操作留日志并能撤销。

## 3. 产品形态

macOS 菜单栏原生应用（SwiftUI `MenuBarExtra`），不在程序坞显示。只做 Mac。界面方向：以「容量仪表」为主，融合「涨幅雷达」和「待清理收件箱」（三版预览见 [design/ui-v1.html](design/ui-v1.html)，线上版 https://claude.ai/artifact/9nCn3UbjdfmtNwo4MYjjTW）。

### 3.1 菜单栏图标
显示剩余空间（如 `91G`）。可用低于 60 GB 变橙，低于 30 GB 变红。

### 3.2 面板
- 顶部：可用 / 总量、健康状态、磁盘构成色条。
- 标签「下载」：按类别分组的勾选清单，默认只勾「建议清理」的组，一键移到废纸篓。
- 标签「看不见的」：按风险分三级。
- 标签「涨幅」：7 天可用空间曲线，加上「谁涨的」排行，每行带处理按钮。
- 标签「提醒」：各条提醒规则的开关。

### 3.3 每周卡片
每周五 18:00 通知，点开后逐张决定：移到废纸篓 / 保留（以后不再问）/ 下周再问。卡片：下载文件夹里能清的每个分组一张，「要你决定的」每项一张；对话记录和缓存不进。「保留」按项记，涨了超过 1 GB 再问；「下周再问」到下一次周报，周五 18:00 前点的顺延到下周五。

### 3.4 桌面悬浮球（第 8 批）
- 48 点的圆球，图标是「扫帚浮游兽」（定稿图和生图过程见 `design/fuyou-icon/`，应用里用的是 `assets/floating-ball.png`）。浮在所有窗口上面，每个桌面、全屏应用里都在。
- 默认贴右边，在随手记猫球正下方空 14 点；拖动后松手贴最近的左边或右边，按显示器记位置（UserDefaults）。
- 点一下在旁边打开和菜单栏同一个面板（同一份数据）；再点球、点别处或按 Esc 收起。菜单栏图标保留。
- 可用低于 60 GB 时球左上角亮橙点，低于 30 GB 亮红点（和菜单栏图标同阈值）；悬停提示「磁盘瘦身 · 可用 XX」。
- 「提醒设置」页有「显示桌面悬浮球」开关，默认开。

## 4. 规则

### 4.1 下载文件夹（`~/Downloads`）
| 类别 | 判定 | 默认 |
|---|---|---|
| 安装包 | `.dmg` `.pkg`，添加日期超过 7 天 | 建议清理（勾选） |
| 已解压的压缩包 | `.zip` 等普通文件（不含名字像压缩包的文件夹），同目录有同名文件夹 | 建议清理（勾选） |
| 久未打开 | 30 天没打开过（`kMDItemLastUsedDate`，为空时用 `kMDItemDateAdded`） | 列出，不勾 |
| 最近的大文件 | 7 天内、大于 300 MB | 只提示，不能勾选 |
| 已标「保留」 | 带 Finder 标签「保留」 | 永不建议 |

### 4.2 看不见的
| 风险 | 内容 | 怎么清 |
|---|---|---|
| 安全（可再生） | `work/*/.claude/worktrees/*/target`（第 7 批）：前提是 Rust 构建目录（有 `Cargo.toml`、`target` 被 git 忽略）、无未提交的已跟踪改动、路径里没有符号链接；「没在用」三道一起判——worktree 没被 git 锁住、cargo 锁文件没被占（没在编译）、没有进程的工作目录或可执行文件在里面——外加 `target/` 往下三层 2 小时内未改动。已落地（PR 已合并且停在合并时的提交，或者当前提交已在远端主分支里）的默认勾选，可进自动清理；没落地但闲置 ≥ 3 天的归「要你决定」，不默认勾选、不进自动清理。执行前把「没在用」再判一遍；删除时持有 cargo 锁、先改名挪到暂存目录再删。git 命令一律加 `--no-optional-locks` | 删除 `target/` |
| 安全（可再生） | npm、uv、pnpm、pip 缓存 | 各工具自带的清理命令；上次几乎没释放的不再默认勾选 |
| 安全（可再生） | Homebrew 下载缓存（`~/Library/Caches/Homebrew/downloads`），Homebrew 在运行时跳过 | 删除该目录；不用 `brew cleanup`（会删已安装软件的旧版本、自动卸载依赖） |
| 安全（可再生） | Playwright、Puppeteer 下载的浏览器（无进程在用时） | 删除 |
| 需确认 | Codex 备份快照（`~/.codex/recovery`）、npx 运行过的工具（`~/.npm/_npx`）、长期未用的 Colima 虚拟机、Cowork 虚拟机 | 用户逐项确认后移到废纸篓；虚拟机只给出处理办法 |
| 只展示 | Claude / Codex 对话记录、项目源码、各应用数据目录 | 工具永不删除 |

### 4.3 提醒
- 可用低于 60 GB：图标变橙；低于 30 GB：系统通知。
- 某个被跟踪的目录一天涨超过 10 GB：单独通知。
- 每周五 18:00：瘦身周报（每周卡片）。
- 自动清理「安全」项：默认关闭，打开后只在可用低于 60 GB 时执行，两次之间至少隔 2 小时；应用每 5 分钟读一次可用空间，比上次扫描时掉了 8 GB 以上（且离上次扫描至少 30 分钟）就马上扫描；只清「看不见的」里安全、默认勾选的项，下载文件夹里的用户文件一律不自动动；用户正在确认清理或刚清完还能撤销时不插队；清理命令和直接删除的不能撤销。
- 提醒和自动清理只在打包版（.app）里运行；同一条提醒一天只发一次，周报一周一次，首次安装不补发之前的周五；「其他」和废纸篓的涨幅不单独提醒。

## 5. 安全底线
- 用户文件只移到废纸篓，不直接删除；永不自动清空废纸篓。
- 「只展示」的项任何路径都删不了，有测试保证。
- 清理前必须可预览，执行前按规则复核会随时间变化的条件；每次操作写日志；撤销从最近一次往前逐次进行，放不回的项下次还能再试；日志损坏时先留底不覆盖。
- 任何一层是符号链接、带 `.` 或 `..` 的路径一律不清；清理命令必须对应它自己的位置；沙盒自测（`--home`）不运行清理命令。
- 不用 `sudo`，不改系统设置，不改任何项目的代码或配置。

## 6. 技术选型
- SwiftUI + SwiftPM，用命令行工具编译（本机没有完整 Xcode），用脚本打包成 `.app` 并本机签名。
- 巡检在应用内用定时器执行，不用 launchd（避开全局坑 G-05）；需要用户授权一次「完全磁盘访问」。
- 开机自启用 `SMAppService`，开关在「提醒设置」页，默认关，只有装进「应用程序」后才能开。
- 安装用 `scripts/install.sh`；本机签名（ad-hoc）每次重新打包都会变，「完全磁盘访问权限」要先删掉旧条目再重新加。

## 7. 分批计划

| 批 | 内容 | 验收 |
|---|---|---|
| 0 | 项目起步：目录、git、协作骨架、本需求 | 骨架齐全，测试通过，首次提交 |
| 1 | 扫描引擎（无界面）+ 命令行工具 `diskslim scan` | 单元测试覆盖各规则；真实磁盘扫描结果与 2026-11-05 手动排查一致 |
| 2 | 清理执行与安全：预览、进废纸篓、工具命令、日志、撤销 | 清理与撤销可还原；「只展示」项删不了 |
| 3 | 菜单栏界面：先出融合版界面预览（3 版）给用户挑，再实现 | 实际运行截图与预览一致 |
| 4 | 涨幅追踪：每日快照、7 天曲线、谁涨的；开机自启 | 构造涨幅场景，排行正确 |
| 5 | 提醒与每周卡片 | 用假数据触发每种提醒并确认收到通知 |
| 6 | 打包上线：装到「应用程序」，引导授权，真实磁盘验收；问用户是否停掉每日巡检任务 `disk-space-guard` | 用户使用一周无误删 |
| 8 | 桌面悬浮球（见 3.4）：先定图标，再做贴边小窗、点开面板、拖动贴边、告急圆点、设置开关 | 装机后在真屏上：默认在猫球下方，点开 / 收起面板，拖到左右边贴边，重开后位置还在 |

每批做完停下，等用户确认后再做下一批。
